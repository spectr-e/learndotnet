# Learn .NET

A repository containing practice code for .NET and C#, built while following the [Microsoft Learn](https://learn.microsoft.com/en-us/dotnet/) training paths.

## Topics Covered

### C# Fundamentals

- Variables, data types, and basic operations
- Decision logic (`if`/`else`, `switch` statements)
- Arrays and `foreach` loops
- String formatting and interpolation
- Methods and parameters
- Guided projects: FizzBuzz, Petting Zoo, Mini-Game

### .NET Essentials

- Debugging and dependencies
- File handling and I/O

### ASP.NET Core Web APIs

- Building RESTful APIs with controllers (ContosoPizza, Fruit API)
- Minimal APIs (PizzaStore)

### Blazor

- Component-based UI with Blazor
- Event handling, data binding, and state management
- Guided project: BlazingPizza ordering app

## Prerequisites

- [.NET SDK](https://dotnet.microsoft.com/download) (8.0 or later recommended)

## Getting Started

```bash
git clone https://github.com/spectr-e/learndotnet.git
cd learndotnet
```

To run a console project:

```bash
cd <project-folder>
dotnet run
```

To run a web project:

```bash
cd <project-folder>
dotnet watch
```
